# Nagrik Setu – AI-Powered Civic Issue Management Platform

## Overview

Nagrik Setu is an intelligent civic issue management platform designed to bridge the gap between citizens and municipal authorities. The system enables citizens to report civic problems such as potholes, broken streetlights, water leakage, overflowing drains, and other infrastructure-related issues through a simple mobile application.

Unlike traditional complaint portals that often lack transparency and accountability, Nagrik Setu provides end-to-end issue tracking, automated complaint routing, real-time status updates, and AI-powered verification of completed repairs.

---

## Problem Statement

Citizens frequently encounter civic infrastructure issues, but existing complaint management systems suffer from:

* Lack of transparency in complaint handling
* Manual complaint categorization and routing
* Difficulty identifying responsible authorities
* Limited tracking of complaint progress
* Premature closure of unresolved complaints
* Absence of accountability mechanisms

Nagrik Setu addresses these challenges by creating a transparent, automated, and accountable complaint resolution ecosystem.

---

## Key Features

### Citizen Complaint Reporting

* Capture and upload issue photographs through a mobile application
* Add issue descriptions
* Automatic GPS location detection
* Real-time complaint submission

### Intelligent Complaint Routing

* Automatic issue categorization using AI
* Geographic ward identification
* Automated assignment to the relevant municipal department
* Elimination of manual complaint sorting

### Multi-Level Municipal Dashboard

The platform supports a structured municipal hierarchy:

#### Municipal Corporation Head

* City-wide analytics dashboard
* Complaint heatmaps
* Department performance monitoring
* Duplicate complaint analysis

#### Ward Head

* Ward-specific complaint monitoring
* Local performance metrics
* Worker activity tracking

#### Department Head

* Complaint assignment management
* Workforce allocation
* Resolution monitoring

#### Department Worker

* Direct task notifications
* GPS-based navigation to issue locations
* On-site complaint handling

### Real-Time Complaint Tracking

Citizens can monitor:

* Complaint status updates
* Assigned department details
* Assigned field worker information
* Resolution progress in real time

### AI-Powered Resolution Verification

To prevent false complaint closures:

1. Workers must upload an "after-repair" image from the issue location.
2. The system compares the original complaint image with the repaired image.
3. AI-based image verification determines whether the issue has been genuinely resolved.
4. Successfully verified complaints are marked as **Resolved**.
5. Incomplete or incorrect repairs are automatically rejected and returned to **In Progress** status.

---

## System Workflow

1. Citizen captures issue image.
2. GPS coordinates are automatically recorded.
3. AI categorizes and routes the complaint.
4. Complaint is assigned to the appropriate ward and department.
5. Department Head allocates the task to a field worker.
6. Worker visits the location and performs the repair.
7. Worker uploads proof of completion.
8. AI verifies the repair using before-and-after image analysis.
9. Complaint status is updated and the citizen is notified.
